# it-asset-manager
효율적인 전산 자원 관리를 위한 부서별 하드웨어/소프트웨어 라이선스 통합 관리 대시보드(Vibe Code 활용 신속 개발 프로젝트)

# 🖥️ 공기업 맞춤형 부서별 전산 자산 관리 대시보드

본 프로젝트는 공공기관 전산실의 자산 관리 및 소프트웨어 불법 사용 방지(라이선스 관리) 업무 효율화를 목표로 기획된 프로토타입 웹 애플리케이션입니다.

## ✨ 핵심 기능
- **부서별/팀별 필터링 조회:** 조직 구조 기반의 자산 보유 현황 모니터링
- **라이선스 만료 알림 (D-Day):** 불시 소프트웨어 점검 대비 만료 임박(30일 이내) 자산 하이라이트 기능
- **자산 CRUD:** 하드웨어(PC/노트북/네트워크 장비) 및 소프트웨어 등록/수정/삭제 관리

## 🛠️ 개발 특징
- **Vibe Code (AI) 활용:** 자연어 기반 요구사항 정의를 통해 하루 만에 UI/UX 및 비즈니스 로직 프로토타이핑 완성
- **코드 검증 및 보완:** AI 생성 코드의 데이터 무결성 검증 및 예외 처리 로직 직접 구현
